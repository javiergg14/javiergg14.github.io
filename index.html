A story-driven Metroidvania in which you control a slime that can transform into animals it has met along the way. Lost in a forest twisted by magic, you gain new movement abilities and use them to explore, solve puzzles and fight bosses.

My role: gameplay programmer. I programmed the main character from start to finish.

Pangolin Studios~16 people

What I did

  • ProgrammingProgrammed the main character from start to finish in C++, using SDL and Box2D.
  • ProgrammingMovement kit: jump, double jump, glide, dash, wall slide, wall jump and pushing objects, each one switched on as the player unlocks it.
  • ProgrammingAnimation state system for the player, with priorities between states so the right animation always wins.
